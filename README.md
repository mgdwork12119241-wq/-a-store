# ستورِي — Storey

واجهة أولية لمنصة طلبات وخدمات ومحلات، جاهزة للنشر على Cloudflare Pages.

## الموجود حالياً
- واجهة RTL عربية responsive.
- دخول كزائر.
- تسجيل دخول / إنشاء حساب **تجريبي محلي** عبر LocalStorage.
- بحث عن الطلبات والفئات.
- أكثر من 25 فئة.
- بطاقات محلات ومنتجات تجريبية.
- صفحة/نافذة تفاصيل المحل وإضافة المنتجات للسلة.
- سلة طلب محلية.
- تصميم مناسب للموبايل والكمبيوتر.

## تشغيل
المشروع Static بالكامل: افتح `index.html` مباشرة أو انشر المستودع على Cloudflare Pages.

## الخطوة التالية للإنتاج
ربط Supabase أو Backend حقيقي للمصادقة، المستخدمين، المحلات، المنتجات، الطلبات، الدفع، العناوين، التوصيل ولوحة الإدارة.
